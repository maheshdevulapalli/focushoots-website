# Focushoots — Landing Page

A single-page static website for Focushoots.

## Files
- `index.html` — page content
- `style.css` — responsive styling
- `script.js` — mobile navigation + WhatsApp lead form
- `assets/focushoots-logo.png` — uploaded Focushoots logo
- `assets/whatsapp-qr.png` — uploaded WhatsApp QR code

## Deploy on GitHub Pages
1. Back up your current repository first.
2. Replace the site's current `index.html`, `style.css`, and `script.js` with these files.
3. Keep the `assets` folder in the repository.
4. Keep your existing `CNAME` file if your current custom domain uses one.
5. Commit/push the changes.
6. GitHub Pages will publish the landing page.
